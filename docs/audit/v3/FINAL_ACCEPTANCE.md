## 6. Documented Minor Limitations (Non-Blocking — Transparent Operational Notes)

1. **`V3-SEC-P3-01` — Next.js 16 Default `10 MB` Proxy Body Limit on `>10 MB` Audio (`P3`):** `src/proxy.ts` matches `/api/*`, so Next.js 16's default `10 MB` `proxyClientMaxBodySize` rejects `>10 MB` audio uploads fail-closed (0 bytes stored) as HTTP `400 BAD_REQUEST` instead of exact `413 PAYLOAD_TOO_LARGE` (`validateAudioUpload()` itself returns `413`, and `>5 MB` images return exact `413`). Configuring `experimental.proxyClientMaxBodySize: "16mb"` in `next.config.ts` in V3.1 will preserve exact `413` on `>10 MB` audio and full 10–15 MB `.docx`/`.pdf` multipart import headroom.
2. **`SH-044` (Inherited V2.1) — Upstream Moderate `uuid` Advisory Inside `exceljs`:** `npm audit --omit=dev` exits `1` due solely to 2 moderate advisories (`exceljs@4.4.0 -> uuid <11.1.1`, GHSA-w5hq-g745-h8pq), `0` Critical, `0` High. StudyHub generates UUIDs solely via `node:crypto` and never invokes `uuid` v3/v5/v6 buffer APIs. Do **not** run `npm audit fix --force`.
3. **In-Memory Sliding-Window Rate Limiting (Multi-Instance Scaling Note):** `src/lib/security/rate-limit.ts` provides deterministic per-instance rate limiting ideal for single-node/small deployments; multi-region serverless scaling should optionally back it with a shared store (see `docs/DEPLOYMENT.md`).
4. **Zero-Copy Cross-Owner Media Clone Lifetime (`V3-DB-OBS-01`):** `clone_study_set()` preserves Storage quota on Supabase Free Tier by referencing existing `media_assets` rows rather than duplicating Storage objects across owner prefixes; if Owner A later revokes Collaborator B's share on Set A, B's live signed-URL read on Set A's private media prefix ends (while historical exam snapshot media remains strictly readable via `exam_attempts` RLS).
5. **Post-V3.0 Optional Performance & UX Polish (`V3-PERF-P2-01/02`, `V3-UX-P3-01..04`):** Bounded concurrency (`4`) for multimedia DOCX uploads & PDF image downloads, conditional dynamic `katex` loading, minor DOCX Step-4 preview `A.` prefix cleanup, English TTS quick-hint pill in Spell Mode, Practice Setup initial confidence switch visual sync, and Vitest `.mjs`/ESM config warning cleanup.

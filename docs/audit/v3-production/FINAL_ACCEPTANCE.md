## 4. Documented Minor Limitations (Honest Operational Disclosures)

1. **Cross-Region Function Latency (`PROD-PERF-01` — Actively Scoped in V3.1):** Vercel Functions currently run in `iad1` (US-East) while Supabase Cloud runs in `ap-northeast-1` (Tokyo). Users in Vietnam/APAC experience cross-Pacific multi-hop latency (especially noticeable on mobile 4G and sequential multi-request workflows). StudyHub V3.1 is already underway to co-locate functions to `hnd1` (Tokyo) alongside mobile-first UX & frontend/backend latency optimization.
2. **Inherited Moderate Transitive Dependency Advisory (`SH-044`):** `npm audit --omit=dev` reports `0` Critical, `0` High, and `2` Moderate transitive advisories (`exceljs@4.4.0 -> uuid <11.1.1`, GHSA-w5hq-g745-h8pq) on unused `uuid.v3/v5/v6` buffer APIs. StudyHub uses Node's `crypto.randomUUID()` exclusively; `npm audit fix --force` is intentionally avoided to prevent breaking `exceljs`.
3. **Free-Tier Platform Boundaries ([`docs/FREE_TIER_LIMITATIONS.md`](../../FREE_TIER_LIMITATIONS.md)):** Supabase Free's built-in SMTP enforces ~2–4 emails/hour (free custom SMTP in Dashboard removes this ceiling for larger groups) and pauses projects after 7 consecutive days of zero traffic (1-click Dashboard restore, zero data loss). Vercel Hobby is strictly for personal/non-commercial projects.
4. **Transient Upstream Storage Retry & Minor UX Polish (`PROD-OPS-01`, `PROD-UX-02/03`):** Adding 1 bounded 500ms retry on large `>4 MB` `study-temp -> study-media` copies, updating landing `/` hero copy from V2 (`6` modes) to V3 (`8` modes + PDF + Offline PWA), adding a 1-tap `EN` voice toggle in Spell Mode, and performing a brief physical iOS/Android spot check (supplementing Chromium viewport emulation) are logged cleanly for V3.1.

## 6. Documented Minor Limitations & Operational Notes (Non-Blocking)

All items below are non-blocking, affect zero P0/P1/P2 requirements, and are transparently documented for production operators and future V2.2 polish:

1. **`SH-044` / `SEC-019` (P3 Upstream Moderate Transitive Advisory):** `exceljs@4.4.0` depends transitively on `uuid@8.3.2` (`GHSA-w5hq-g745-h8pq`, moderate; **0 Critical / 0 High** in `npm audit --omit=dev`). StudyHub uses `node:crypto` exclusively for all tokens, IDs, and shuffling; `npm audit fix --force` was intentionally NOT run (would downgrade `exceljs` to broken `3.4.0`).
2. **In-Memory Rate Limiter Scope (`P3-4` / `SEC-021`):** `src/lib/security/rate-limit.ts` uses a process-local sliding-window `Map`. Suitable for single-node/self-host deployments; for multi-region serverless scale, migrate to Upstash Redis or PostgreSQL-backed counters (documented in `docs/DEPLOYMENT.md`).
3. **Playwright Local Concurrency on 16GB Hosts:** `playwright.config.ts` leaves `workers: undefined` locally (auto-spawning `13–16` Chromium instances on 32-thread hosts, which can exhaust 16GB RAM). Run Playwright locally with `--workers=4` (verified `13/13` in `10.6s` and `16/16` in `1.7m`).
4. **Live `EXPLAIN (ANALYZE, BUFFERS)` Plan Dump:** Live 500Q DB benchmarks (`#110`), 10k-Q deterministic engine benchmarks (`#75`), and Supabase Cloud Performance Advisor (`unindexed_foreign_keys = 0`) all passed; capturing a formal 10k-row Postgres `EXPLAIN (ANALYZE, BUFFERS)` plan remains optional post-launch capacity tuning.
5. **Optional P3/P4 UI & Tooling Polish Backlog:**
   - `BUG-040` (P3): Non-fatal Vite CJS deprecation notice on `vitest.config.ts:1:1` (all 187 tests pass).
   - Direct binary upload of embedded DOCX images to `study-media` (dead `/docx-media/` paths safely stripped with `EMBEDDED_IMAGE_SKIPPED`).
   - Optional UI controls for active backend features: custom expiry date picker in `ShareDialog` (API/RPC enforce `expires_at`), dedicated "Blocked Users" tab in `FriendsView` (block API & `blocked_by` RLS active), full-text reveal popover for `line-clamp-4` in `MatchClient` (`LM-07`), and `sets/route.ts:54,124` 100-shared-set slice (`P2` edge note only if a single user has >100 shared sets simultaneously).
   - Minor cosmetic observations (`USER_EXPERIENCE_REPORT.md` §9.3): 2 transient `/dashboard?_rsc=...` `404` logs during `/login -> /dashboard` transition (invisible to user), duplicate `"Thi thử tùy chỉnh"` label in desktop sidebar (quick-action + nav link), DOCX Step-4 preview showing `[A] A.` when raw DOCX options include literal prefixes (Exam Runner renders clean single `[A]`), 404 `<title>` remaining VI in EN mode while `<h1>`/body localize cleanly (`P4`), and `F` hotkey precedence over 6th option on 6-option questions (digit `6` selects Option F, `P3`).
